# 📊 Análisis de Ventas

Este proyecto consiste en un análisis exploratorio de datos (EDA) sobre un conjunto de datos de ventas, con el objetivo de identificar patrones, tendencias y métricas clave del negocio.

## 🎯 Objetivos

* Analizar la estructura de los datos
* Identificar valores faltantes
* Explorar el comportamiento de las ventas a lo largo del tiempo
* Calcular métricas como ingresos e impuestos (IVA)
* Visualizar tendencias de ventas

## 🛠️ Herramientas utilizadas

* Python
* pandas
* numpy
* matplotlib

## 🔍 Análisis realizado

Se realizaron las siguientes tareas:

* Carga y limpieza de datos
* Análisis exploratorio (EDA)
* Cálculo de nuevas variables:

  * Ventas totales
  * IVA
* Agrupación de datos por fecha
* Visualización de la cantidad vendida a lo largo del tiempo

## 📈 Principales insights

* Se observan variaciones en la cantidad vendida según la fecha
* Existen valores faltantes que deben ser considerados en futuros análisis
* Las ventas presentan patrones que pueden ser útiles para la toma de decisiones
